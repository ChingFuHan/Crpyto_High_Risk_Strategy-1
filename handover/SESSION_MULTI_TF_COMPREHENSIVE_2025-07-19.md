- **4 種時間週期配置**: 1h / 15m / 5m 個別 + 1h+15m+5m 多週期共同決策
- **3 項新策略功能**: 動量排名進場、盈虧比出場、認錯買回機制
- **完整手續費模型**: 0.08% 手續費 + 0.05% 滑價 + 混合資金費率

## 四、關鍵發現

### 1. 時間週期比較
- **1h 表現最好**：最高報酬率、唯一 4/4 窗口獲利、但 MDD 也最大 (~26%)
- **15m 風險調整後最佳**：PF 最高 (1.45)、勝率最高 (79%)、MDD 適中 (18%)
- **5m 最保守**：報酬率最低但 MDD 也最低 (16%)、交易頻率低
- **MTF 對 5m 幾乎無改善**：+0.004 PF、因 5m 的 EMA 已隱含多週期對齊

### 2. 策略功能測試結果
- **動量排名進場**：僅對 1h 有幫助 (PF 1.13→1.22)，5m/15m 都會劣化
- **盈虧比出場 (1:1/1:2/1:3)**：全部無效——緊密移動停損 (2.5-3%/1%) 總是先觸發
- **認錯買回機制**：全部劣化——加入的交易品質較低

### 3. 跨時間週期通用最佳參數
- **移動停損**: 啟動 2.5-3% / 距離 1% — 所有週期通用
- **RSI 區間**: 60-72（15m/5m）或 50-80（1h 較寬鬆）
- **成交量倍率**: 1.5-2.0x — 過濾低成交量假突破

### 4. MTF 多週期共同決策
- 5m 的 EMA 參數 (108/252/600/2400) 已等效於 1h 的 EMA (9/21/50/200)
- 額外加入 1h/15m 趨勢過濾僅微幅改善 (+0.004 PF)
- 結論：**不需要額外的多週期共同決策**，5m 內建的長期 EMA 已隱含此功能

## 六、技術決策記錄

1. **Quality Metric**: `PF × min(1.0, trades/30)` — 防止小樣本過擬合
2. **Fast Mode (5m)**: Phase 1 用單年窗口加速，Phase 2 + WF 用完整 3 窗口驗證
3. **MTF 向量化**: 原始 Python dict 查找 (50M+ entries) 改為 numpy searchsorted，建表時間從 30+ 分鐘降至 < 1 秒
4. **PF Cap**: profit_factor 返回 "∞" 字串時封頂為 10.0
